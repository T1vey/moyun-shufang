速机械臂速度

画线和空中移动使用同一个速度（控制器程序速度百分比，0～100）。保存后立即生效（SDK 控制时，正在绘制的这一幅也会马上改速），不需要重启，已有规划仍然有效。速度越快，转角越容易被削圆、线条越容易抖；请逐档提高，并在旁守着急停。

设绘画区域与落笔标定

将笔尖移到绘画区域的两个对角点，分别读取 A、B；移到纸面落笔位置后获取落笔点。采集期间保持机械臂静止，读取按钮不会移动机械臂。

两点顺序不限，保存时自动计算范围；最后抬笔高度从纸面算起。“原软件速度”只是 ArmVision 导入的记录值，不影响实际执行；实际速度在上方“机械臂速度”中设置。

控制器连接与坐标选项

A/B 与落笔点通过原 Web 接口读取；七轴、法兰及工具核对通过 SDK 网口读取。板子有线 IP 必须已配置在实际网卡上，此处保存不会修改网络。控制器未到货时可留空。
