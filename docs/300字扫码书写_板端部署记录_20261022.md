## 验证结果

- 板端 Python 3.8 / ARMv7 环境运行 111 项测试：首轮 110 项通过，1 项因板子旧 Node 不提供全局 AbortController 导致测试脚本失败；修正测试脚本按实际环境选择分支后，该项重跑通过。生产代码无需因此改变。
- 显式加入 `tests/__init__.py`，防止被系统同名测试包遮蔽；补齐部署包中的回归测试依赖。
- 手机 API 确认字库 300 字、字号 40～70 mm、现代横排、真实运行模式。
- 输入“一二三四五六七”：40 mm 自动排为 3 列×2 行、2 页；70 mm 为 1 列×1 行、7 页。实测两次预览分别约 0.413 / 0.567 秒；这只是该简单文本的预览耗时，不是整页七轴规划或实写耗时。
- Wi-Fi 地址上的手机 HTML、JS、CSS 和配对预览接口可访问。
- 液晶显示桥输出正常，1024×600，原 FPGA 帧校验正常；浏览器健康探测响应约 0.022 秒。
- 用户确认：“屏幕正常，手机预览正常”，对应屏幕/触摸正常及扫码输入“一二三”预览成功。
- 部署前后无活动绘画任务，未提交真实运动请求，未驱动机械臂。

部署时机械臂连接侧 eth1 的 carrier 为 0，因此尚未进行真实墨迹测试。需要接通控制器链路后再做首个字的实写验收。

## 使用

手机连接 ESP8200 → 重新扫描屏幕二维码 → 毛笔写字 → 输入字库中的汉字 → 选择 40～70 mm → 预览排版。确认后使用“提交并开始书写”；多页需换好纸后再继续。

## 回退

确保没有正在执行的书写任务，在板子上运行：

```sh
sudo bash /home/xilinx/tcb705_deploy_backups/20261022_text300_r1/rollback.sh
```

该脚本撤销本次新增的服务覆盖配置，将工程链接切回旧版本，重启应用和显示/触摸服务。它不改写机器标定，也不替换 FPGA。当前已完成用户验收，无需执行回退。
