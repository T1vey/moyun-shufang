# 线稿图库与统一界面

## 行为

“选择本地线条图”现在直接打开应用内图库。全部已保存线稿以缩略图网格显示，支持滚动浏览、按名称搜索、点选大图预览和“使用这张线稿”。选择后点击主页“生成绘画预览”，仍需预览完成和单独确认才能开始绘画。

“导入线稿”是图库内的补充入口，可一次选择多张 PNG/JPG/WebP。导入保存到数据目录的 `lineart_library/`，刷新页面、重启服务后保留；内容相同的图片自动去重。限制仍为单张 20 MB、1600 万像素、静态图片。没有云端请求，浏览与导入不会规划或运动。

自动汇总三处明确的图片目录：`<data-dir>/lineart_library/`、`<data-dir>/cloud_images/`、`~/Pictures/SO101/CloudImages/`。只读这些图片目录，不遍历电脑其他文件。电脑原有图库中的 14 张线稿及其元信息已打包到板子，保留电脑原文件。

## 样式

主页、图库、设置页和绘画确认弹窗统一使用 `base.css` 的字体与深棕/焦糖金色变量、圆角、印章标题、44 px 触摸按钮。设置页移除了独立的内联配色与字体。主要选择流程不再出现系统文件选择窗口；只有主动导入新图时调用浏览器文件选择器。

绘画确认改为同一主题的应用内弹窗，要求重新勾选“核对预测图、有人守在急停旁、周围无人”。确认绑定当时的 job_id/revision，任务更新后需重新确认。既有机械臂保护和运动流程继续生效。

1024×600 屏幕上图库为缩略图网格与右侧大图；窄窗口改为两列缩略图与底部选中预览，列表可滚动，确认按钮固定在底部。
