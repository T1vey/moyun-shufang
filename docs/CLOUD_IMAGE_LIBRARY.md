# PC 云端图片保存与历史选择

云端生成成功后，ArmStudio 自动保存原始图片和生成时间、模型、主体等信息。默认图片库是当前 Windows 用户的 `Pictures/SO101/CloudImages`，与项目目录、临时目录和板卡分开保存，重启 GUI 或更新软件仍能读取。

## 使用

1. 在 GUI 的云端生成区域点击 **历史云端图片**。按生成时间显示图片，选择后右侧显示预览。
2. **使用此图片**：将线稿放入当前图片输入框，之后可调整绘画尺寸，点击 **提取笔画 → 上传**。
3. **使用并上传板卡**：使用当前绘画尺寸直接提取笔画并登记到板卡。不需要再次云端生成；上传后再规划、执行绘画。
4. **另存当前云端图…** / **另存选中图…**：将原图另存到自选位置。
5. **打开图片库**：在资源管理器查看保存文件。图片与同名 JSON 描述文件应一起保留，单独保留图片也可以读取。

历史窗口可离线查看。板卡未连接时，不能完成上传；图片继续保存在 PC，连接后可重新选择并上传。选择新图片会清空之前的图片 Job 和规划 Job，避免使用错误轨迹。

同一秒内生成多张图也不会相互覆盖。PNG、JPEG、WebP 等使用其真实格式扩展名，保存与另存都保留原始字节，不重新压缩。图片库仅存图片和必要描述信息，不保存云端密钥。

## 自定义目录

```powershell
python scripts/arm_studio.py --target-drawing --cloud-image-dir "D:\SO101云端图片"
```

以后启动时使用相同参数，就会读取该目录。`--show-cloud-history` 可在启动后直接打开历史窗口。

本次更新已将本电脑仍可读取的旧 `Temp/so101_cloud_*/lineart.*` 图片复制到默认图片库，按内容去重并保留旧文件时间。旧记录标为“历史导入”，由于旧版未保存模型和主体，这些信息可能未知。旧临时文件保持原样。

该功能位于 PC GUI，无需重新生成或烧录 FPGA 比特流。交付包同时包含更新后的 GUI 和图片库模块。
