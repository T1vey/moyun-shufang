# TCB705 · ZYNQ7020 绘画机械臂（糖画坊）

用 ZYNQ7020 控制天链 TCB705 七轴机械臂画画：图片 → 中心线笔画 → **ZYNQ 本地七轴规划（FPGA 加速逆解）** → 把规划好的路径作为程序下发给机械臂控制器执行。

> 旧版 README（含 FPGA 加速、部署、SO101 历史等完整记录）保存在 [docs/legacy/README_旧版_20261017.md](docs/legacy/README_旧版_20261017.md)。

## 2. 整体流程

```
手机/电脑传图 ──► 图像处理 (vision.py, stroke_paths.py) ──► 笔画 paths.json
                                                              │
                         ┌────────────────────────────────────┘
                         ▼
       tcb705/planner.py  本地规划：笔画排序 → 抬笔/移动/落笔 → 0.5 mm 细分
                          → 七轴连续 IK（tcb705/planning_batches.py：板上 FPGA 批量，失败退回 CPU）
                          → C2 重定时 → FK 校验 → 预测图
                         │  冻结保存：plan.json + trajectory.bin + nodes.json（SHA256）
                         ▼
       tcb705/web_executor.py  关节节点 → hmcRobotFree 程序（joint 模式）→ 分段
                          → tcb705/web_control.py：登录 → 切自动 → 等稳定 → 下载程序 → 启动
                          → 路径跟踪监控（偏差/Z 下限/无进展）→ 停止/高处恢复手动
                         ▼
                  TCB705 控制器 192.168.4.4:8010 → 机械臂
```

## 4. 快速开始

### 4.1 电脑上离线演示（不连机械臂）

```powershell
run_tcb705_demo.bat
# 或：
.\.venv\Scripts\python.exe scripts/run_tcb705.py --simulation --profile robots/tcb705/profile.demo.json --data-dir build/tcb705/demo_ui
```

浏览器打开 `http://127.0.0.1:8095/`。

### 4.2 连真机画图（电脑直连控制器）

1. 电脑网口接控制器，网口加 `192.168.4.x` 地址（管理员 PowerShell）：
   `New-NetIPAddress -InterfaceAlias "以太网" -IPAddress 192.168.4.21 -PrefixLength 24`
2. 启动后端（读真实位置、允许实机执行）：
   ```powershell
   .\.venv\Scripts\python.exe -B app.py --robot tcb705 --port 8785 --data-dir build/tcb705/real_ui --allow-real --tcb-profile robots/tcb705/profile.armvision_joint.json
   ```
3. 先只规划，看预测图：`.\.venv\Scripts\python.exe scripts/tcb705_web_draw.py --circle 30`
4. **有人守在急停旁、周围无人**后执行：`.\.venv\Scripts\python.exe scripts/tcb705_web_draw.py --plan-job <上一步的ID> --execute`

### 4.3 部署到 ZYNQ

板子：PL 口 `eth1=192.168.4.23/24` 接控制器 `192.168.4.4`，PS 口 `eth0=192.168.2.99` 接电脑。电脑公钥 SSH 已可用；joint 发布已位于 `/home/xilinx/tcb705_releases/20261018_joint_r1/ZYNQArm`。激活命令如下（会先备份配置；需要 sudo）：

```bash
ssh -t xilinx@192.168.2.99 "sh /home/xilinx/tcb705_releases/20261018_joint_r1/ZYNQArm/deploy/tcb705/activate_joint_release.sh"
```

### 4.4 运行测试

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_tcb705 tests.test_tcb705_web tests.test_tcb705_kinfit
```

## 5. 安全约定

- 每次真实运动前先 dry-run，并在聊天中确认“有人守在急停旁、周围无人”；界面执行请求还必须带 `confirm_physical: true`。
- 竖直笔（UVW 180,0,180）的落笔法兰高度 **Z = 219.3 mm**，不得低于此值；214.31 是历史倾斜笔姿态的数据，不能用于当前竖直笔。
- 手动↔自动切换可能瞬时下沉 7～15 mm，切换前必须离纸 ≥60 mm。执行器检查起点和终点；故障停在低处或反馈不可读时不自动切模式，也不自动抬笔。
- 不清除报警、不改保护设置、运动请求失败不自动重试。
- `config/secrets.local.json` 含密钥，不要外传；不要在日志、文档或聊天中记录密码。
