# 绘画尺寸选择

版本：1.5-drawing-size。GUI「选择图片」区域提供 100×100、200×200、300×300 mm，以及自定义宽高（2–300 mm）。这里是线稿画布在纸面上的毫米尺寸，不是屏幕预览像素或自动扩充机械臂工作空间。

选定尺寸后提取笔画，中心线直接按该毫米范围生成。对于已经上传的笔画，也可以改尺寸后直接重新规划：板端从原始上传坐标独立缩放，保留笔画顺序、原图摘要和线段数量，重算路径长度及摘要，不反复累计缩放。该方式不会从原图增加新的细节；若需要重新提取细节，可在改尺寸后再点「提取笔画」。

改尺寸会清除当前旧计划选择，保留可缩放的上传笔画；重新规划成功后才能按新尺寸执行。预览、落笔/抬笔目标、整数计数检查及历史计划使用同一份缩放后的几何。规划日志显示实际宽高，历史中选择新版计划时也会同步显示其保存尺寸。

100、200、300 mm 以原有纸面中心为中心，按纸面 u/v 方向放大。不会修改笔轴、接触高度、关节标定、执行 PI 参数或增加运行时偏差停止。FPGA 接口和比特流继续沿用。

放大图形可降低固定毫米位置偏差占图形的比例，并不能消除接触断线、机构间隙或关节跟随误差。200/300 mm 是请求尺寸；图案能否全部规划成功取决于当前纸面位置、笔姿态及机械臂可达范围。规划器沿用已有 IK 与几何检查，遇到不可达点报告规划失败，不自动缩小尺寸、不丢笔画，也不把未完成规划当成完整绘画。该功能没有新增绘画途中中断条件。

验证：尺寸专项检查覆盖三档坐标缩放、保留源笔画、300 mm 预设完整边界、GUI 尺寸变更不复用旧计划，以及三档实际规划/保存/预览数据的尺寸一致性。API 的规划参数为 `drawing_size_mm: [宽, 高]`，省略时继续使用上传笔画原尺寸。
