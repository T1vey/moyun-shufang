# GUI 绘画效果与逐段顺序预测

选择云端线稿或历史图片，在“提取笔画并上传板卡”区域点击 **预测绘画效果（含顺序）**。仅在 PC 提取和预览，不要求连接板卡，也不会上传或驱动机械臂。云端生成后的原图窗口、历史云端图片窗口也有预测入口。

## 查看效果与顺序

- 初始显示最终预测线条。右侧列出每条落笔线段的全局编号、第几笔画、该笔画内第几段和长度。
- 点击某一段：显示截至这段的绘制效果，并用橙色箭头标出当前段的方向；下方显示毫米坐标。
- 顺序播放、暂停、上一段、下一段、从头查看、最终效果，以及底部进度滑块可逐段查看。
- “标注所有线段序号”显示画面上的全局编号。线段密集时可关闭标号，通过右侧列表查看。
- 可显示原线稿底图、期望路径和抬笔转移示意。抬笔虚线不会当成墨迹或落笔编号。
- 可导出最终预测图 SVG 和完整线段顺序 CSV。

编号依据实际上传的 `paths` 原顺序，不重新排序，也不将连续笔画拆成多次抬笔。每条线段是连续笔画中相邻两个点之间的一段。预览完成后的“提取笔画 → 上传”会复用同一份路径；换图、改尺寸或改线段预算后会重新提取。

## 两种预测

**提取路径预测**：显示图片经过中心线提取、曲线简化和外到内排序后的落笔轨迹，用于检查缺线、重复线和顺序。这是将上传的目标线条，尚未加入运动学或实物误差。

**已规划轨迹预测**：规划成功后点击“已规划轨迹预测”。PC 获取这份规划冻结的原始路径、纸面方向、机器标定及舵机指令，按实际整数计数计算笔尖 FK，并投影到纸面。此时也显示该段对应的指令序号和规划时间范围。灰色为期望路径，黑线为指令采样点的模型预测，橙色为当前段。

该模型不会测量纸面高度误差、舵机间隙、跟踪滞后、笔压力等实际影响。演示播放用于查看顺序，播放速度不代表实际绘画时长。模拟规划明确显示名义模型范围。

## 板端与历史规划

离线路径预测可立即使用。已规划轨迹预测需要安装本次交付包的板端程序。新规划将保存独立快照，重启板端或改变当前标定后仍可以查看原规划的模型预测；是否可执行仍由原有标定检查决定。

此前未保存预测资料的历史规划需要重新规划，不能用当前标定冒充过去的标定。此功能不改变 FPGA 比特流、规划算法或执行命令。
