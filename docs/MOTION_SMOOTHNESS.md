# 平缓运动版使用与验收

软件运动版本：`motion-smooth-v1`，服务版本：`1.4-feedback-drawing`。新增功能与标定步骤见 [跟随补偿与笔轴标定](FEEDBACK_DRAWING.md)。

本版修改 PC GUI、板端 Python 规划器和串口执行器。FPGA 目标 IK 接口、RTL、比特流和寄存器地址保持兼容，沿用现有编译产物。连续执行版已部署至板卡，环境、FPGA 数值和模拟串口检查通过；尚未执行真实绘画验收。

## 已实现的算法

1. GUI 默认选择「速度优先（推荐）」、API 默认 `motion_mode=speed_priority`。新模式使用旧式共享割线速度与零节点加速度，不再求解最小 jerk 节点；原 `smooth_fast`、`gentle` 仍供选择，`standard` 保留原曲线用于离线比较。标准版和旧运动算法的历史计划可查看预测，真实绘画需要新版执行契约。
2. 按笔画、阶段变化、显式停点和大于 45° 的尖角分块。块内共享关节节点速度和加速度，通过带宽固定的 LDLᵀ 求解最小积分平方 jerk。关节反向只约束该关节速度，不强迫全部加速度清零。
3. 每个块的起终点速度和加速度为零，连接处保持位置、速度、加速度连续（C2）。本版限制 jerk 的绝对值，未宣称 jerk 在所有节点连续（C3）。
4. 「速度优先」使用 V=0.72 rad/s、A=4 rad/s²、J=200 rad/s³，一轮重定时，取消原先低 jerk 导致的时间膨胀，替换旧保守标量配置；单独填写的每关节限值仍有效。其余模式维持原参数：平缓 V=0.12/A=0.3/J=20，平滑加速 V=0.36/A=0.9/J=10。归位使用速度优先，单关节点动仍使用平缓。
5. 利用细分 Bernstein 包络检查整段速度、加速度和关节限位，解析求二次 jerk 的端点和内部极值。「平滑加速」默认两轮重定时，「平缓」最多四轮，已有显式轮数配置保留；最终按块统一伸长并对齐固定 50 ms 网格，再完整检查 V/A/J、限位和实际采样，轮数减少不跳过终检。
6. 对全部动作阶段检查每段 17 个探针和全部实际发送采样的 FK 路径、笔轴误差；单批不超过 1024 点。几何不合格时分块降低自由导数比例，必要时回退到保守曲线，再检查 jerk。失败或预算超限明确报错，不删线、不绕过误差检查。
7. 保留云端线稿保存、图库选择、中心线、外到内排序和一笔连续绘制流程。新指令记录原始线段编号，预测窗口按这些编号对应绘画顺序。

## 执行方式

串口由一条执行线程独占。目标写入以 20 Hz 为参考，位置/原始速度读取默认约 10 Hz，扭矩检查约 1 Hz；电压、温度、负载按关节轮询。完整五关节反馈共用 12 ms 读取预算。日志写入另一个有界队列，日志线程不操作串口。

自 `1.2-motion-continuous` 起按用户要求取消运行时偏差阈值自动中止。主机写入结束后保留发送间隔，避免延迟后追赶发送。调度迟到、写入耗时、反馈年龄、跟随偏差、反馈读数范围、运行中扭矩与温度状态只记录诊断，不中止绘画；旧 `following_hard_counts` 和 `lateness_fault_s` 不再触发停止，`strict` 不再因为运行时质量偏差终止新算法。日志积压允许丢弃日志条目并记录数量，日志保存失败也不停止运动。

自 `1.3-speed-priority` 起取消反馈偏差引起的运行时降速，公共进度速率保持 1，不再降到 0.5 或 0.25。自 `1.4-feedback-drawing` 起，反馈还用于有界 PI 目标补偿；LOWER/LIFT 边界最多各补偿 0.3 秒，预算结束继续，DRAW 中途不因偏差停顿。正常发送按周期起点保持 20 Hz，不将每次 FK/串口写入耗时额外叠加到下一周期；延迟后依然不追赶发送。规划阶段用于保持图形几何的必要停点仍属于轨迹本身。

串口写超时从 10 ms 调整至至少 50 ms；写超时或短写重发同一个完整目标，重发期间不消耗后续轨迹点，通信恢复后继续且不追赶发送。持续无法写入时任务保持重试，不报告虚假的绘画成功。心跳失联、运行时长、终点误差均不再自动中止；终点反馈至多等待 1 秒，未确认时记录真实状态并继续归位。用户主动停止仍有效，执行线程在发送及重发时检查停止请求并尽力保持位置。本版没有新增普通暂停后继续功能。

点动和归位使用同步的静止到静止五次曲线。归位直接平滑返回配置的起始关节姿态，沿用用户配置的 `home_height_offset_m`，取消自动纸面间距检查、强制预抬笔及到位确认门槛。可选 FK 纸面预测仅记录诊断，不拒绝归位。

## 舵机参数

速度寄存器是运动上限，并非带方向的速度前馈。默认速度码从 100 提至 200，已有明确 `speed_codes` 继续优先；不改 PID、死区或 EEPROM。实际加速度寄存器先读取并记录，保持现值。状态为 `existing_acceleration_preserved_unverified`，不能把原始速度码直接换算成已实测的物理速度。

只有完成实际单位标定后，才在 `machine.json.execution.servo_profile` 填写：

- `units_verified: true`；
- `speed_codes`、`acceleration_codes`：单个整数、按五关节顺序的数组，或按舵机 ID 的对象；
- `speed_unit_rad_s`、`acceleration_unit_rad_s2`：实测换算系数；
- `verified_registers`：对应的 `firmware`（major/minor）、`velocity_unit`、`maximum_acceleration`、`acceleration_multiplier`，可统一填写或按 ID 分别填写。

这些字段没有可直接套用的实机数值。程序校验当前固件和单位寄存器、配置能力及最大加速度，然后保持当前位置，发送地址 41、长度 7 的显式配置并回读。验证失败不通过故障保持命令写入该加速度配置。

## 配置与旧计划

机器标定文件继续复用。不要用示例配置或离线验收快照覆盖实测零位、方向、限位、笔尖或纸面。新配置选项只补充默认值，不要求重新标定。

历史计划保存多项式描述和执行契约，恢复后验证网格、导数、限位、C2、阶段和显示指令的一致性。旧运动版本、旧绘画版本、标定变化或端口变化的真实计划需要重新规划。自 `1.2-motion-continuous` 起取消新计划的 2 计数起点拒绝条件：位置不一致时，以执行前的实际反馈为起点，增加至少 1 秒的静止到静止平滑接入段，再按保存的原轨迹绘画。接入段裁剪到原契约内的平缓速度、加速度和 jerk，在同一个调度器内执行，不要求再次精确到 2 计数，不修改 DRAW 坐标或笔画顺序。日志 `START_ALIGNMENT` 和执行结果 `start_alignment` 保存起点偏差及接入时长。该 MOVE 段是关节空间过渡，pen_down=false 仅表示阶段；没有独立硬件抬笔器，也不构成纸面避碰路径规划。

机器 JSON 可补充 `home_q_rad` 定义归位的五关节姿态；未填写时沿用原来的关节参考姿态，但抬高 IK 使用当前机器模型和当前纸面。

## 离线结果与本次加速对照

冻结复杂图：`20261003_220947_074835_legacy_52871452.png`，100 × 100 mm，36 笔、474 原始线段、1193 IK 目标。

| 指标 | 原运动算法 | 上版平缓 | 本版平滑加速 |
| --- | ---: | ---: | ---: |
| jerk 峰值 rad/s³ | 99.319 | 12.305 | 8.986 |
| 最大节点 jerk 跳变 rad/s³ | 约 186.2 | 18.852 | 15.425 |
| 非必要内部全关节停速 | 旧版有大量停速 | 0 | 0 |
| DRAW 最大模型路径偏差 mm | 保持旧几何检查 | 0.229 | 0.210 |
| 发送参考周期 | 每 IK 段重新取点 | 固定 50 ms | 固定 50 ms |
| 指令数 | 6995 | 11607 | 7010 |
| 预计绘画时长 s | 321.147 | 580.350 | 350.500 |

对这张图，加速模式预计比上版平缓快 1.66 倍，耗时减少约 39.6%，同时 jerk 峰值和节点跳变更小。209 个必要静止节点仍保留；速度和加速度节点跳变约 4.3e-16 / 4.0e-15。曲线保持 C2，整幅 474 条原始线段的预览对应完整，不删线或抹掉必要转角。不能把这一倍数套用于所有图片或直接当作实机速度。

上版平缓三轮 PC 完整规划及生产历史保存中位数为 1.447 秒。本版加速为 1.377、1.162、1.146 秒，中位数 1.162 秒。两轮与四轮重定时的预计运动时长只差约 0.55 秒，默认采用两轮以降低计算工作；完整几何与导数终检保留。此结果不包含 HTTP、真实舵机预检或 ARM 的计算开销，不能用于宣称 Zynq 复杂图已达到 30 秒。

数值与模拟串口测试不代表真实笔迹、振动、舵机接收时间或机械间隙已测量。

## 更新与实机验收

使用随包 `deploy/deploy_z20.ps1` 安装软件，沿用当前 bit/hwh/registers；板端共享 `~/so101_data` 的机器标定及图库保留。`-Offline` 表示板端依赖使用离线安装，不表示部署可以在没有板卡网络时执行。

重启 PC GUI 与板端服务，确认版本 `1.4-feedback-drawing`、执行策略 `speed_priority_feedback_corrected`、运动版本 `motion-smooth-v1`。旧新算法计划可直接受益于取消自动降速；要获得更短的新参考轨迹，选「速度优先（推荐）」重新规划。笔轴或接触高度标定后须重新规划。原始图库、中心线、顺序预测和 FPGA 比特流继续使用。

本次用户样例（426 目标）离线同输入预计时长从 127.1 秒降至 67.75 秒；原始线段缺失数 0，模型路径最大偏差 0.181 mm。此前板端真实执行记录耗时约 390.1 秒，包含自动降速；不能把新指令时长直接当作已测量的实物完成时间。冻结复杂图（1193 目标）预计从 350.5 秒降至 180 秒，原始线段缺失数 0。

先用小尺寸直线、圆、方形，再测试鸭子和冻结复杂图。检查笔尖接触压力、机构紧固及供电，同时导出事件日志：必要停点、跟随误差、反馈年龄、发送间隔 p50/p99/max、迟到计数、结束到位以及归位结果。模型跟随误差使用当前持有目标的 FK 参考，原始图线误差另行记录；串行测量每个关节带独立时间戳，仍不是同步物理笔尖测量。

板端可通过 `scripts/benchmark_planning_speed.py --motion-mode smooth_fast --overlay ... --paths ... --machine ... --q0 ... --runs 3 --output ...` 测试完整规划及历史保存。改为 `--motion-mode gentle` 可做平缓对照。该脚本不打开舵机；测试 PL 时须先停止其他使用该 IK IP 的板端服务。30 秒验收要求三次均不超过 30 秒，同时轨迹和量化检查全部通过；真实 GUI Job 还须计入网络、预检和响应耗时。

本版尖角默认保形停速，没有启用自动圆角。实时内存环形缓冲替代全量命令保存、普通暂停恢复、实机单位标定和硬件振动闭环属于后续优化；本次不宣称这些已交付。
