# 系统架构

## 输入与交互

`user_gui/` 提供板端网页、手机扫码、任务进度与确认；`calligraphy/` 管理字库、笔画模块和文字排版；`handwriting/` 负责逐笔会话；`user_gui/hwr.py` 在 ARM 上用 OpenCV DNN 完成 3755 类识字。照片风格化可调用云端，本地字库、线稿与识字可离线使用。

## PS：场景与轨迹

`vision.py` / `stroke_paths.py` 从图像得到笔画；`tcb705/` 将纸面坐标、抬落笔、冗余关节连续性与时间规划结合，选择 CPU 或 PL 逆解后端。`native/tcb_planner/` 实现原生批处理与几何计算。PS 保留控制器通信、任务所有权与停止处理，PL 的结果经现有接口交给控制器执行。

## PL：批量七轴逆解

`hls_source/tcb705_parallel_fp32/` 以三级 DATAFLOW 将几何分解、CORDIC/连续选解和顺序写出重叠。几何与选解为 FP32，反正切内部采用定点 CORDIC；DDR 缓冲布局沿用 FP64 打包 ABI，并非全链路传输宽度减半。失败返回成功前缀，近奇异或不支持模型由 PS 处理剩余目标。

| 通道 | 当前用途 |
|---|---|
| AXI HP0 | 显示 |
| AXI HP1 | IK 控制与目标输入 |
| AXI HP2 | 视觉模块 |
| AXI HP3 | IK 结果写回 |

完整平台还集成显示、触摸、GE_PL 与音频。具体平台能力以对应 `overlay/*/platform.json` 与匹配的实际 bit/hwh 为准。

## 执行与约束

TCB705 为七轴主线；根目录保留的 SO-101 模块只用于旧接口兼容。运行时不重复执行所有旧 FK 探针检查，开发验证使用独立 FP64 正解作参考。关节限位、有限值、连续性、时间约束、任务锁和停止接口仍由当前代码定义。计算误差、规划时间与实物落纸效果分别评估。
