## 2. FPGA 与 CPU 的分工

七轴 FK、Jacobian、连续 IK 使用 `native/tcb_planner/core.cpp`，板上生成 ARM32 本地动态库；笔画编排、时间参数化和任务管理由 Python/NumPy 执行。后端报告 `ik_backend=ZYNQ_CPU_NATIVE_7R`。

**本次没有运行 Vivado/HLS 综合、布局布线或位流生成，也没有重新下载 FPGA。** 原显示、触摸平台继续使用；旧 SO101 五轴规划核不参与天链七轴计算。已有平台名称中包含 `planner`，不表示天链工程已经调用它加速。

- 当前平台 build_id：`planner_v2_r2_fused_20261011`。
- 已有 bit SHA256：`4402779ccb121c7529cffa55df55ec9eda9afc73c8fa6b9cbbe536ffb5bb8bd8`。
- manifest SHA256：`8bd5c1cac5ca842d513591bccef6c760b0353b0155e4c2c855e039908f541104`。

若后续增加七轴 FPGA 加速，需要为七轴模型和数值格式设计匹配的计算核、PS/PL 驱动和对照测试，然后重新综合与验收。不能直接把旧五轴位流当作七轴加速器。

## 5. 现用参数和真实运动边界

正式屏幕服务以 `--allow-real --no-browser` 启动，未使用 `--simulation`；这里 `allow-real` 只允许配置后的只读反馈，**不表示机械臂运动已实现**。

ArmVision 原参数已装入：A=(-509.605,-67.854) mm，B=(-359.390,80.666) mm，落笔 Z=206.31 mm，UVW=(180,0,0)°，机器人 ID=1，笔间抬高 8 mm，末笔抬高 60 mm，程序速度原值 100%，swap_xy=true。原速度百分比仅保留，未当作本地算法的 mm/s 使用。

控制器 IP 仍为空。TCP、基座与控制器坐标关系、七轴顺序/符号/零位和实际动态限制未完成核对。接口明确报告 `physical_ready=false`。实际参数下的规划不会把未确认的工具与坐标映射假定为正确；真实执行接口仍拒绝运动。

剩余工作：填写并验证真实控制器连接；静态反馈与 FK 对照；核实 TCP 和坐标映射；确认透传周期、缓冲/断流/停止契约；实现并验证 `PluseToServo` 真实执行状态机；低速空载到实际绘画逐步验收。

## 6. 运维和回退

查看状态：

```sh
systemctl status tcb705-ui so101-md0700r so101-gt911
```

查看后台日志（可能含手机配对链接，不宜公开整段日志）：

```sh
journalctl -u tcb705-ui -n 80 --no-pager
```

恢复原界面：

```sh
sudo bash /home/xilinx/ZYNQArm/deploy/tcb705/rollback_board_service.sh
```

回退脚本停止显示/触摸，撤下本次显示覆盖配置，禁用新业务服务，再恢复原显示和触摸；保留天链源码和数据。不要直接删除原系统、虚拟环境或 platform 文件。

初次源码包为 `dist/TCB705_20261017_board.zip`，451 个文件的 SHA256 已在部署前核对。补入本轮部署脚本、截图和文档后，最终源码包为 `dist/TCB705_20261017_deployed_source.zip`；板端同步时重新核对最终包的 `DELIVERY_SHA256.json`，板上编译产物和数据保持原位。
