# 跟随補偿与绘画高度反馈

版本 1.8.4-feedback-release，执行策略 speed_priority_feedback_corrected。沿用当前 FPGA 比特流和速度优先轨迹。

JointFeedbackController 持续用原规划与编码器之差更新位置补偿，保留机器配置中的上限、滤波和变化率。本机计数上限为 64，变化率为 80 计数/秒，滤波为 0.08 秒。跟随或方向偏差仅记录并纠偏，不自动停止，也不改变绘画段的规划速度。

NormalFeedbackController 在 DRAW/LOWER 将编码器模型法向误差转换为联合关节修正，尽量保持横向位置和笔轴。默认增益 0.6、死区 0.15 mm、额外高度上限 4 mm；与普通关节补偿共用总计数上限。反馈暂缺时额外高度修正逐步退回零，普通绘画继续；这不等于已经确认真实纸面接触。

绘画、落笔与抬笔曲线的反馈读取周期为 50 ms，串口指令保持单线程拥有。抬笔由 MeasuredPenRelease 持续闭环完成，实际模型上抬和纸面高度达到设置门槛后才横移，避免仅按时间猜测已抬笔。缺读保持上一支持目标并重试，不用跟随误差中断。具体流程与持续缺读行为见 PEN_TRANSITIONS.md。

在控制交接时重新以最新支持目标初始化绘画控制，清除旧笔画动态误差。新增法向修正不会跨笔画残留。没有改舵机内部 PID、EEPROM、速度单位或加速度寄存器，没有恢复起点相差 2 计数拒绝执行的条件。

GUI 提供笔轴、轻触高度、三点校正和实际笔尖固定点 TCP 标定。数据保存到板端长期 machine.json，适用于当前实物安装。三点与垂直笔轴不能替代笔尖偏移测量。具体一次标定步骤见 CONTACT_PLANE.md。

实际执行轨迹预览显示编码器模型重建，执行记录包含原目标、下发目标、实测计数、法向修正与抬笔高度确认。它不是相机墨迹测量。顺序读取五个编码器并非同时采样，没有压力传感器，不能据此声称真实压力恒定。

新增验证包含不同关节响应时间、独立负载偏置、末点横向追赶、临时缺读、持续缺读与手动停止、控制交接、整数计数量化，以及整张真实已保存计划的虚拟串口执行。模型试验通过后仍由用户确认实物墨迹效果。
