# 单笔 CPU 低延迟：第二轮计算原型

2026-10-22。本轮代码仅在本地工程和板端 `/tmp/tcb-latency-check-20261022` 隔离目录测试。
没有连接机器人 SDK，没有使能或运动，没有替换正在运行的界面，没有改写机器标定。

## 板端结果

ZYNQ7020 / ARMv7，同一当前机器配置；40 mm 模块，假定在起笔前 20 mm、纸面上方 8 mm 悬停。
输入模板生成、进程启动和假定起点 IK 在计时外；表内包含单笔几何规划、原生七轴 IK、实际 SDK 角度舍入、合并检查、插值碰撞检查和结果摘要。
测试采用 CPU，不占用 PL。每个笔画测 3 次，尚不能据此给出 P95/P99 或最坏情况承诺。

| 笔画 | 节点数 | 最终段数 | 单笔计算总耗时 |
|---|---:|---:|---:|
| 横 | 281 | 44 | 0.630～0.674 s |
| 垂露竖 | 256 | 37 | 0.573～0.642 s |
| 长撇 | 283 | 35 | 0.600～0.619 s |
| 横折 | 364 | 53 | 0.780～0.807 s |

第一轮横笔完整准备为 0.938～0.973 s。本轮同一完整规划器在模板缓存优化后为 0.857～0.910 s。
新的专用原型横笔为 0.630～0.674 s，但它与完整规划器的输出契约不同，不能宣传成原有完整 C2 规划已经同样提速。
所有结果均为计算时间，不包含触摸识别、SDK/控制器延迟、开始运动或笔尖接触纸面的时间。

## 改动

1. 毛笔采样曲线加入最多 64 条的不可变模板缓存；键包含全部 XY、压力、速度控制点和缩放。每次返回独立数据，修改模板或比例会使用新键。没有缓存跨位置复用的关节角。
2. 模板重建校验保持完整比较，归一化旧速度元数据时只复制被修改的字典，避免再深拷贝所有笔画坐标。
3. 新增 `tcb705/short_stroke.py::compile_single`，只接受单个已有合法毛笔笔画，只研究 SDK 关节目标模式。
4. 从原规划器复用纸面检查、初始关节与笔轴检查、连续七轴 IK、失败细分和节点碰撞检查。原生链成功前缀批量接收；遇到失败/非有限值/关节跳变，丢弃后续推测结果，以原有细分逻辑重新求解。
5. 角度先按真实发送流程进行四位小数格式化和 float32 舍入，再对将要发送的关节段检查路径、姿态、纸面范围、下压上限、关节限位、插值碰撞和抬落笔单调性。
6. 专用原型不生成 SDK 关节点执行器不会使用的 C2 时间曲线与 4 ms 帧流。它不宣称满足原完整规划器的速度、加速度、jerk 时间律；这些运动参数如何与控制器实际插补对应，仍需单独验证。

## 禁止误用的接口边界

原型输出 schema 为 `tcb705-short-stroke-research-v1`，带有 `execution_ready=false`、`physical_authorized=false`、`timing_source=controller_not_commissioned`。
它不是正式执行计划。`artifact.freeze`、`artifact.save` 明确拒绝这种输出；旧执行器同样不能把该 schema 当作 `tcb705-plan-v1` 执行。
原有正式规划入口仍生成完整时间曲线，原型未接入 GUI 或常驻 SDK 下发。

新增 9 项离线测试覆盖：与原规划器几何一致、失败前缀细分一致、非有限 IK 结果重新求解、精确匹配 SDK 序列化、限位和碰撞拒绝、模板压力篡改、多笔拒绝、取消、不连接 SDK、研究结果禁止冻结、缓存不可变。板端与本机均通过。
另外本机 14 项原书法模块测试通过。

## 后续真正降低“松手后等待”的工作

- 在进入手写模式时完成模板预热、通信初始化和一次性就绪处理。
- 手写期间完成可复用的采样、分类候选和几何处理；固定屏幕到纸面的映射。最终笔型、比例、压力曲线变化时必须使相应准备结果失效，不复用错误的关节轨迹。
- 建立连续 SDK 会话和有界笔画队列，笔间抬笔悬停，不重复归位或切换控制模式。
- 对真实关节段验证控制器时序与笔轴行为后，再集成计算原型。未验证前不取消现有实机执行保护。
- 分别测量松手、计算完成、SDK 接收、首次反馈运动与落纸；第一条指令已发出不等于机械臂已经开始书写。
