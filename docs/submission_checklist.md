# 参赛提交导航

对应用户提供的 AMD 2026 选题指南及提交页面。页面要求的 GitHub 链接为：

**https://github.com/T1vey/moyun-shufang**

| 材料 | 本仓库 / 本地交付 |
|---|---|
| 工程代码 | 当前仓库应用、RTL/HLS、测试、部署脚本与模型输入 |
| 设计与架构 | `architecture_overview.md`、`hardware_build.md`、原技术文档 |
| 验证与资源 | `validation_summary.md`、`hw/reports/`、`reports/` |
| AI 协作与复用技能 | `ai_collaboration.md`、`skills/pynq-release-audit/` |
| 作品海报 | `posters/` 中三版 PNG / A3 PDF；可挑选后上传 |
| 演示视频、承诺授权书、实物全貌 | 由实际拍摄与签署材料提交，本次未制作或代签 |

上传页面列出：视频 MP4/H.264、3 分钟内且 300 MB 内；技术 PDF 50 MB 内；全部代码 RAR 200 MB 内；海报 PDF 或 PPT 50 MB 内。仓库链接不替代页面的其他必填文件。原始 2 GB ZIP 不适合作为该页面的代码归档。

指南末尾另要求进入决赛的自主选题队伍按官方模板准备 **一页英文、A4 彩印海报**。这里的三版中文 A3 是当前作品海报选稿；已有本地英文 A4 需结合最终选择与官方模板单独核对。

公开内容不添加学校、指导老师、队员姓名。原始报告保留作者/主机/本地构建路径等技术来源信息；本次新增展示材料均使用项目署名。
