# 绘画位置与实物几何校正

版本：1.6-drawing-alignment。沿用当前 FPGA 比特流、速度优先和编码器 PI 执行器。

## 右移与转移抬笔

GUI 绘画区提供横向、纵向位置偏移，以及独立的「转移抬笔高度」。本次机器设置为沿 GUI 原图横轴向右 50 mm、纵向 0 mm、转移抬笔 12 mm。落笔平面高度微调沿用 -4 mm，纸面原点、关节零位和笔轴均保留。

横移对应图案 X 正方向，不是固定增加某个舵机计数。规划前将整幅图的空间目标一起平移，LOWER、DRAW、LIFT 和笔画间 TRAVEL 使用相同新位置，不裁掉左侧线段。起始接入段从实际当前位置连接到新图的起点；归位仍回原配置的归位姿态。

转移抬笔 12 mm 相对当前落笔平面；它与「落笔高度微调」是两个独立参数。只增加离纸转移的高度行程，落笔速度限值保持原值，实际总时长会随额外抬笔行程及新位置的关节运动变化。更新位置后自动重新规划当前图，不自动执行。

没有新增运行中跟随误差、姿态偏差或纸面预测自动停止，PI 上限和舵机内部 PID 保持原值；手动停止仍有效。不能用继续发送指令解决物理零件阻挡，右移后的机械间距仍需实物确认。

## 为什么不能根据照片直接拉高和旋转

200 mm 试验的两次实际执行记录中，腕部跟随偏差最高 77–78 个计数，编码器 FK 模型笔轴偏差接近 10°；模型笔尖路径最大偏差约 12.8 mm。目标写入未失败。模型预测转移高度的部分反馈仍低于设定绘画平面，可能形成落笔转移连线；没有接触传感器，不能据此确定墨迹接触时刻。

当前模型工具笔尖平移仍为 [0,0,0]，已测量的是笔轴方向，不能据此宣称完整 TCP/关节几何已经校正。长笔夹会放大腕部角度误差对实际笔尖位置的影响。照片透视、纸面坐标误差和模型尺寸也会影响整体比例与倾斜，直接从照片猜拉伸系数会混入这些因素。

## 三点实物几何标定

1. 在纸面标基准中心 C（不是右移 50 mm 后的图形中心）。标 X 在 C 的右侧，Y 在 C 的下方；C→X 与 C→Y 距离相同，默认 100 mm，可填写实际用尺量出的间距。标记采用与当前 GUI 原图一致的横向与纵向方向。当前云端线稿为 XY 向下的画布；旧 XY 向上的外部路径，其 Y 标记应沿该路径的正 Y 方向。
2. 保持笔杆垂直，手动调整到笔尖轻触 C，点击「记录 C」。再分别在 X、Y 轻触并记录。读取来源可以是板端或 PC COM 口，所有记录只读编码器，不发送运动、扭矩或 PID 指令。
3. 点击「应用三点校正」。程序以三个实际标记的已知距离和其编码器模型位置，计算图案毫米坐标到模型平面坐标的 2×2 仿射矩阵及基准平移，用于修正整体比例、旋转和斜切。
4. 图案偏移也经过该矩阵换算，所以右移 50 mm 仍沿实物标记的图案横向。旧计划清除选择，当前图重新规划；不会自动执行。先验证方框、圆和本次图案，再确认大尺寸效果。
5. 「恢复未校正」清除这项实物 XY 校正，保留右移、接触高度和转移抬笔参数。配置修改前后快照保存到 Pictures/SO101/Calibration。

只有得到三个实物点后才应用几何系数，目前不会默认加入猜测拉伸。三点可修正全局仿射误差，不替代完整工具长度/偏置、关节零位与机构背隙标定，也不能校正局部卡滞。当前版本保持现有纸面法向与落笔高度，不从三点自动推断新的压力或高度。

## 保存与预览

`paper.drawing_offset_mm` 保存图案毫米偏移，`trajectory.lift_m` 保存转移抬笔高度。`paper.xy_calibration.matrix/translation_mm` 保存实物 XY 校正。普通机器没有 XY 校正时使用单位矩阵。

计划冻结 `canvas_to_plane_matrix`、新平面原点及绘画偏移。整数指令预览与编码器重建使用矩阵的逆投影返回图案坐标，保留原笔画编号；窗口另显示相对纸面基准的偏移量。预览中的图案形状不因纯平移改变，不能把模型预览当作实物墨迹测量。
