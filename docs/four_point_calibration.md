# 四点纸面标定

当前板端使用四点模式，旧三点记录不参与当前绘画。2026-10-09 已按用户要求强制应用实测残差 14.9108 mm 的一组四点，并保存为默认标定。

正常启动会从板端持久保存的 `machine.json` 加载标定，不要求重新采点。GUI 显示“已加载保存的四点标定，无需重新采点”。PC 默认备份在 `Pictures/SO101/Calibration/default_four_point.json` 和工程 `config/four_point_calibration.local.json`，板端默认备份在数据目录的 `calibration_defaults/default_four_point.json`。

## 采点

在固定的平整纸面上量出一个 200 × 200 mm 正方形：

```text
A 左上 ── 200 mm ── B 右上
  │                    │
200 mm              200 mm
  │                    │
D 左下 ── 200 mm ── C 右下
```

相邻边均为 200 mm，对角线约 282.8 mm。GUI 的“正方形实测边长”默认 200 mm；四点必须属于同一个正方形。

1. 点击顶栏“四点标定”。使用与绘画相同的笔、夹持长度、底座和纸张位置。
2. 手动将笔保持垂直，笔尖轻触 A，点击“记录 A 左上”。记录按钮只读取关节位置，不驱动机械臂。
3. 按相同方法依次记录 B、C、D。不要用压弯笔尖或纸面的姿态采点。
4. 点击“应用四点校正”，查看拟合误差。遇到交叉、重复或过大残差提示时，检查点位并重新采集。
5. 应用成功后重新规划，再测试小图。绘画中心设在正方形中心；原来的横纵偏移、接触高度微调归零。

未完成标定时，规划、绘画、回绘画起始位保持禁用。采点草稿自动保存在 `Pictures/SO101/Calibration/four_point_draft.json`，配置一致时可重开 GUI 继续。

## 实现与范围

四组实物轻触位置对应的关节读数通过现有机械臂模型计算位置，用四点等权最小二乘拟合一个三维仿射纸面。平面内的比例、倾斜和纸面高度一起进入规划、预览及执行反馈；不会重新启用 TCP 矫正。

四点不是逐点强行拉伸。200 mm 边长时，默认拒绝最大拟合残差超过 5 mm 的数据。用户可勾选“允许超过残差门槛”后应用；系统保留真实残差和用户强制接受记录，重启及绘画校验也认可此记录。此选项仅放开残差门槛，重复点、交叉点、过期关节/模型配置等检查仍有效。残差不能当作实物绘画精度保证。

纸面抬笔方向依据现有向上的纸面法向确定，图像上下方向由 A/B/C/D 决定。修改模型或关节标定会使旧采点失效，需要重新采点。
